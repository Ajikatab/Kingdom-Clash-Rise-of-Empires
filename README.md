# Kingdom Clash: Rise of Empires

A fork-based Unity project for an RTS-style game.

## Features
- Camera and character-selection systems
- Building placement and interface elements
- Tactical ability systems

## Project origin
This repository is a fork of [bayuramdhan50/Kingdom-Clash-Rise-of-Empires](https://github.com/bayuramdhan50/Kingdom-Clash-Rise-of-Empires). Preserve that attribution when presenting the project.

## Tech stack
- Unity and C#
- Universal Render Pipeline (URP)

Open the project using the Unity version recorded in `ProjectSettings/ProjectVersion.txt`. Resolve packages through Unity Package Manager. The repository is large; allow sufficient disk space and import time.

## Testing
No project-specific test suite was identified. Unity editor and play-mode validation were not performed during this documentation update.
